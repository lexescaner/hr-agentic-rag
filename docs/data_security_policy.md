# Data Security Policy

## Data Residency Requirements
Company systems classify countries into three tiers for data residency purposes:
- **Tier 1** (EU/EEA, UK, US, Canada, Australia): no additional restrictions for remote work.
- **Tier 2** (approved list maintained by Legal, e.g. Singapore, Japan): remote work permitted with
  standard VPN and device encryption requirements.
- **Tier 3** (all other countries): remote work requires explicit Legal and Security approval; company
  data may not be accessed from Tier 3 countries without an approved exception.

## Home Network Requirements
Employees working remotely must:
- Use company-issued VPN software for all access to internal systems.
- Ensure home Wi-Fi uses WPA2 or WPA3 encryption.
- Avoid accessing company systems over public/unsecured Wi-Fi without VPN.

## Device Requirements
Only company-issued or company-approved encrypted devices may be used to access confidential company
data. Personal devices require MDM (Mobile Device Management) enrollment before use.

## Incident Reporting
Suspected data security incidents (lost device, phishing, unauthorized access) must be reported to the
Security team within 24 hours via the internal security ticketing system.
